# 🩸 Donor Profile - Android Application

A responsive Donor Profile registration screen built for Android devices using XML layouts and Java.

## 🚀 Key Features Implemented
* **Responsive Layouts:** Implemented a standard nested `ScrollView` system that maintains viewable contexts when input modes shift.
* **Resource Binding:** Leveraged native `string-array` assets inside `strings.xml` to populate user selections cleanly.
* **Event Handlers:** Embedded core conditional parameters within Java Click Listeners to process data states securely.

## 📱 Hardware Testing & Deployment
This application version has been fully compiled, executed, and validated on a physical **Redmi** device framework:
* **UI Checks:** Soft keyboard toggles adjust the interactive layout smoothly without compressing lower workflow menus (`adjustResize`).
* **Spinner Operations:** Drops choices accurately across active window matrices without unexpected clipping.
